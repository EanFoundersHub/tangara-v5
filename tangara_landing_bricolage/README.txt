Tángara Investment Readiness - Landing HTML

Archivo principal:
- index.html

Cómo publicarlo en GitHub Pages:
1. Sube index.html y la carpeta assets/ a la raíz del repositorio.
2. En GitHub, ve a Settings > Pages.
3. Selecciona Deploy from a branch, rama main, carpeta /root.
4. Guarda y espera la URL pública.

Fuente:
- La página usa Bricolage Grotesque desde Google Fonts mediante CSS.
- No se empacan archivos .ttf/.otf de fuente dentro de este ZIP.

Notas:
- Los botones de postulación y descarga están como placeholders (#). Cambia los href cuando tengas los enlaces reales.
- Cada bloque está construido como sección web editable, con altura de pantalla en desktop y ajuste responsive en mobile.
